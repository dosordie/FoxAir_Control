# FoxAir Control mit der Wärmepumpe verbinden

FoxAir Control kann auf unterschiedlichen Wegen mit der Wärmepumpe kommunizieren.

## Direkter Modbus

Der direkte Modbus-Zugang ist die beste Wahl, wenn ein direkter Zugriff auf das Mainboard vorhanden ist.

Damit stehen auch Funktionen zur Verfügung, die über die Cloud nicht oder nur eingeschränkt erreichbar sind.

## WarmLink / LTE

Je nach Anlage kann auch die bestehende WarmLink-/LTE-Verbindung verwendet werden.

Eine ausführliche Anleitung für den Modbus-Zugang über WarmLink gibt es hier:

[HowTo: WarmLink Modbus](../HowToWarmlink_Modbus.md)

## Cloud

FoxAir Control kann außerdem auf Daten der PHNIX-/WarmLink-Cloud zugreifen.

Welche Verbindung sinnvoll ist, hängt davon ab, ob nur Werte gelesen oder auch Einstellungen und spezielle Register verwendet werden sollen.
